## AJAX and FETCH API

### Exercise 1 - Posts upload
External javascript, internal css, fetch GET request and DOM manipulation.

![Ex 1 website](https://github.com/marchesinia187179/website-projects/blob/0b81f3cf6af65ab75a1f0693e696e9eef942b3d0/Lab04/images/ex1.png)

After the click of a button
- Start a GET request
  - Fetch method
- Add each object received from the GET request to the DOM
- Add an error if it doesn't work

Note: use the posts from [jsonplaceholder.typicode.com](https://jsonplaceholder.typicode.com/posts).

### Exercise 2 - Fetch API and Form
External javascript, external css, form inputs and labels, select tag, fetch POST request with headers and DOM manipulation.

![Ex 2 website](https://github.com/marchesinia187179/website-projects/blob/0b81f3cf6af65ab75a1f0693e696e9eef942b3d0/Lab04/images/ex2.png)

Send the form data to the server throught a fetch POST method.

Note: use [httpbin.org](https://httpbin.org/post) for the POST.

### Exercise 3 - Products table
External javascript, internal css, form inputs, DOM manipulation and fetch GET / POST methods.

![Ex 3 website](https://github.com/marchesinia187179/website-projects/blob/0b81f3cf6af65ab75a1f0693e696e9eef942b3d0/Lab04/images/ex3.png)

- Make a fetch GET request to show the first five products
- Compile a form to add a new product and send it
- Make a fetch POST request to add the new product and show it

Note: use [fakestoreapi.com](https://fakestoreapi.com/products) for the fetch methods.
