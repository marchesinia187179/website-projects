### Exercise 1 - Posts upload

![Ex 1 website]()

After the click of a button
- Start a GET request
  - Fetch method
- Add each object received from the GET request to the DOM

### Exercise 3 - Products table
External javascript, internal css, form inputs, DOM manipulation and fetch GET / POST methods.

![Ex 3 website]()

- Make a fetch GET request to show the first five products
- Compile a form to add a new product and send it
- Make a fetch POST request to add the new product and show it
