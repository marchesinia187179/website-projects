# website-projects
A collection of projects to learn how to build a website.

## Premise
These projects are some exercises taken from the Web Technologies course of Computer Engineering bachlor at Unimore.
Them are selected by the professors of the course. I only implemented the exercises and upload them to the repository.
The course is made in Italian so the exercises are impemented in Italian, even if could be some exercises in English.
