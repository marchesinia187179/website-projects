# website-projects
A collection of projects to learn how to build a website.

## Premise
These projects are some exercises taken from the Web Technologies course of Computer Engineering bachlor at Unimore.
Them are selected by the professors of the course. I only implemented the exercises and upload them to the repository.
The course is made in Italian so the exercises are impemented in Italian, even if could be some exercises in English.

## HTML, CSS & HTTP
[Lab01](https://github.com/marchesinia187179/website-projects/tree/d44198120df840fdad89d3bc47b42c3544f1515d/Lab01)
### Exercise 1 - List and CSS
- Add an unordered list with four hypertext elements
- Add a paragraph
- Add an ordered list
- Change the background color
- Change the text fonts
- Modify a list in a menu
### Exercise 2 - CSS and Flexbox
Modify the style of the
- header
- footer
- sidebar
### Exercise 3 - Form
Create a registration form with the following inputs
- text for the username
- password
- email
- radio buttons for the sex
- checkbox for the interests
- select dropdown for the country
Note: use [httpbin.org](https://httpbin.org) for the submit.
### Exercise 4 - Blog
Create a blog with 3 pages
- First page
  - home with a paragraph
- Second page
  - some articles with a title search
- Third page
  - form to contact the blog with a name (text), email, object (text) and a message (textarea)
Add also an header, footer and a navbar.
